    5. 기준 Baseline — 분기 대조 기준선

    인·허가 적용 시 각 고시·기준 원문 부칙 시행일을 국가법령정보센터·국가건설기준센터에서 직접 대조 권장.

    6. 운영 방법 (권고)

    • 단일 대장 + 스냅샷 — 본 대장이 살아있는 정본(常時 갱신). 각 분기 정밀검토 보고서는 그 시점 스냅샷으로 outputs\reports\에 보관.
    • 데이터 기반 구조 — 본 파일은 하단 DATA(JSON)만 갱신하면 표·이력이 자동 렌더링됩니다. 분기마다 changelog에 항목 추가 + waps 상태·버전 갱신 → 재배포.
    • 기준↔WAP 매핑 — 기준 개정 시 baseline의 고시번호를 바꾸면, 해당 기준을 쓰는 WAP만 골라 업그레이드(영향 최소화·누락 방지).
    • 커밋 추적성 — 각 변경 이력에 GitHub 커밋 해시를 남겨 배포본과 1:1 대응.
    • 형상 체크포인트 — 매 회차: React계 CDN 버전 고정 / Cache-First sw.js CACHE_NAME 상향 / 버전표기 [MANMIN-VerX.Y] 통일.
    • 자동화 — 분기 스케줄이 baseline 대조 → 변경 있으면 대장·보고서 갱신안 생성 → 승인 후 배포.
